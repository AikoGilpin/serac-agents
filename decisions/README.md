# Décisions — Architecture Decision Records (ADR)

*Dossier créé le 3 mai 2026. Chaque décision validée par Aiko devient un ADR.*

## Format ADR
- **ADR-XXX** : Titre court
- **Contexte** : Pourquoi la décision est nécessaire
- **Options considérées** : Avec pros/cons
- **Décision** : Ce qu'on retient
- **Conséquences** : Impact positif et négatif

## Décisions en attente
- Protocole chiffrement V1 (simple key vs envelope)
- Modèle guardian/recovery (opt-in ou default)
- Freemium tier (1 Go vs plus)
- Crypto payment vs fiat sponsorship vs both
- Quelles features existantes garder côté humain
